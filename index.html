Donovan LaDuke - Micro-Projects

  • Planner Calendar - Shows 5 weeks of a calendar specified using query parameters, removing the first week if necessary and will fit on a 8.5x11" landscape page when printed

  • Tape Calculator - Calculator with a running "tape" that can be copied and easily pasted into other software to display right aligned calculations

  • Interval Timer - Ad Free interval timer, defaults to tabata timer but can be completely configured using query parameters

What is a micro-project?

  • Portable - Single File, No External Dependencies
  • Source Code Available - Open Source, No Obfuscation
  • Documented - Typed with JS Docs, Covered by Tests

Additional Features

  • Simple Config - All Configuration Driven via Query Params for easy bookmarking
  • Custom Accent - Every page supports a dynamic accent color, use the accent query parameter - try red, orange, yellow, green (default), blue, purple, pink, or grey
  • Free as in Freedom - No ads, No micro-transactions, No subscriptions, No tracking, No data collection
