Interval Timer


Ad Free interval timer, defaults to tabata timer but can be completely configured using query parameters


Use the button to start and pause the timer as needed, refresh your browser to reset the timer


To configure a specific timer, use the relevant query params

  • "sets" for the number of cycles in the timer, defaults to 5
  • "rounds" for number of work timers in each set, defaults to 8
  • "work" for the length in seconds of the "work" timer, defaults to 20
  • "rest" for the length in seconds of the "rest" timer between each round, defaults to 10
  • "break" for the length in seconds of the "break" timer between each set, defaults to 60

This is a micro-project, check the source to see the code and do what you want with it!
